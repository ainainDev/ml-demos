Kernel Trick in Code — RBF on Concentric Circles Day 96 — a dual kernel-perceptron trained live in your browser

Data: two concentric circles (120 points) — no straight line can separate them.
Linear kernel: K(a,b) = a·b + 1 → the boundary stays a straight line → ≈55% accuracy.
RBF kernel: K(a,b) = e−γ‖a−b‖² with γ=2 → the boundary bends around the rings → ≈100% accuracy.
Update rule (20 epochs): if yi·(Σj αjyjK(xj,xi) + b) ≤ 0, then αi += 1 and b += yi.

The classifier is a kernelized perceptron — the dual view of the SVM idea from the video: it only ever uses kernel values K(xj,xi), never explicit 3D coordinates. The linear kernel can only draw a straight line, so it caps out near chance; the RBF kernel’s implicit lift wraps the boundary around the inner circle, just like SVC(kernel='rbf') in the video.
