🔢 Naive Bayes — The Mathematics Day 88 — Naive Bayes, Part 7 · reveal each step of the derivation

Goal: given features X = (x₁, x₂, …, xₙ), pick the class y with the highest P(y | X).
Step 0 of 4

Step 1 — Start from Bayes' theorem

P(y | X) = P(X | y)·P(y) / P(X)
The posterior is the likelihood of the features under class y, times the prior of class y, divided by the evidence P(X). The snag: P(X | y) for many features at once is almost impossible to estimate directly — we'd need to see every combination of feature values in every class.

Step 2 — The "naive" assumption: conditional independence

P(X | y) = P(x₁ | y) · P(x₂ | y) · … · P(xₙ | y)
Assume the features are independent given the class. Then the giant joint likelihood splits into small, one-feature likelihoods we can actually count from training data. It's naive because real features often correlate — but it makes the math tractable, and empirically it works.

Step 3 — Drop P(X): the decision rule

ŷ = argmaxy P(y) · ∏ P(xᵢ | y)
The evidence P(X) doesn't depend on the class y, so it's the same for every candidate class — it only rescales all scores equally and can't change which class wins. Drop it, and the winner is simply the class maximizing prior × product of per-feature likelihoods.

In practice we work in log space — log P(y) + Σ log P(xᵢ|y) — because multiplying dozens of tiny probabilities underflows to zero, while adding logs stays safe. The argmax is unchanged since log is monotonic.
