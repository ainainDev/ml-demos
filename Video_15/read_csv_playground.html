Read a CSV straight from a URL


import io
import requests

r = requests.get("https://example.com/movies.csv")
df = pd.read_csv(io.StringIO(r.text))


requests.get downloads the file's text; io.StringIO wraps that string in a file-like object so read_csv can parse it without a real file on disk. This lets you load public datasets in two lines — no manual download step.







Reading files that don't fit in memory


chunks = pd.read_csv("big.csv", chunksize=10000)

for chunk in chunks:
    process(chunk)   # aggregate, filter, or save — then the chunk is freed


By default read_csv loads the entire file into RAM. With chunksize=10000 it instead returns an iterator that yields DataFrames of 10,000 rows at a time, so memory stays flat while you stream through millions of rows. Reach for it when a file is too big for memory, or when you only need per-batch aggregates like counts and means.
