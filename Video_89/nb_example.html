Verdict –

The 14-day dataset is tiny, so Laplace smoothing (add-one) keeps rare combos — like "overcast" on a no-day — from collapsing to a zero probability and vetoing everything. The same algorithm runs in Python via sklearn.naive_bayes.CategoricalNB(alpha=1.0) — the study page shows the equivalent code. Note how "outlook = overcast" alone pushes P(yes) hard: every overcast day in the data was played.
