⚠️ When PCA fails: with a flat spectrum every component carries the same variance — the curve rises in a straight line, so dropping any component throws away real information. There is nothing safe to cut. (Toggle back to see a healthy decaying spectrum.)

KNN accuracy vs. number of components (the MNIST story)

Accuracy shoots up with the first components, then plateaus near the full-data baseline (dashed) — so a small k trains far faster with barely any loss. Push k too far and you gain nothing.

What this shows: Eigenvalues of a 784-feature digits-like spectrum decay fast — the first ~120 components already hold ~90% of the total variance, so keeping 120 numbers instead of 784 loses little. The red cumulative curve plus the 90% line is how you choose k in practice. The second panel mirrors the MNIST experiment: KNN accuracy climbs steeply and flattens near the full-data baseline, proving the reduced features still work. But if the spectrum is flat (try the toggle), every component matters equally — PCA has nothing safe to drop, and you should not reduce.
