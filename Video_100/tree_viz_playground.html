Idea: a decision tree classifies a flower by asking yes/no questions: petal length ≤ 2.45? then petal width ≤ 1.75?. Below is the same max\_depth=2 Iris tree from the video's dtreeviz diagram. setosa versicolor virginica  ·  yellow glow = the sample's prediction path
