# ml-demos

Interactive demos for the CampusX "100 Days of Machine Learning" notes series.

## Structure

- `Video_1/` — What is Machine Learning? (teach-the-machine-to-add demo)
- `Video_2/` — ...

Each `Video_N/` folder holds the interactive HTML demos for that video.
Open any demo via the hosted render link (raw.githack.com serves them as real pages).
