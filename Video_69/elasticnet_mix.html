Synthetic data: y = 2.5·x₁ − 1.5·x₂ + 0·x₃ + noise, with x₃ ≈ x₁ (correlated inputs, where pure Lasso gets erratic). Solved with coordinate descent, features standardized — the same math sklearn's ElasticNet uses.

What to notice
  • l1_ratio = 0 (pure Ridge): all three curves slide toward 0 smoothly — nothing ever hits exactly 0.
  • l1_ratio = 1 (pure Lasso): the noise feature x₃ (and weaker ones) hit exactly 0 — automatic feature selection.
  • In between (ElasticNet): sparsity plus stability — correlated x₁ and x₃ keep similar weights instead of one randomly dying.
