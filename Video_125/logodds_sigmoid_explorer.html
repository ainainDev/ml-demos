1 · Log-odds ↔ Probability (sigmoid)

0.405
p = ez / (1 + ez) = 0.600
The video's base model: 3 of 5 students placed, so z = log(3/2) ≈ 0.405 → p = 0.6 (dashed marker). Modelling happens in log-odds space; predictions are converted to probabilities with the sigmoid.

2 · The 5 students — base residuals

CGPA values are illustrative (the video only shows split midpoints). Labels: 3 placed / 2 unplaced → base p = 0.6 for every row. Residual r = y − p.

3 · Candidate-split explorer (similarity score & gain)

SS = (∑ r)2 / (∑ p(1−p) + λ), λ = 0 here. Gain = SSleft + SSright − SSroot. The best split becomes the root of the tree.
