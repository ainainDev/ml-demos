🎲 Bootstrap Sampler — where OOB rows come from

Each tree in a Random Forest trains on a bootstrap sample: rows drawn with replacement. A drawn row goes back into the pool, so it can be drawn again — while other rows are never drawn at all. The never-drawn rows are the out-of-bag (OOB) samples: free, unseen validation data.

📈 OOB accuracy as the forest grows

Simulated: each OOB row is predicted by the trees that never saw it, and a majority vote decides. Single trees are noisy; the vote stabilises quickly — which is why oob_score_ is a decent free estimate of accuracy (treat it as a rough gauge, not exact).
