📦 The JSON response

A typical paginated API answer (TMDB-style) looks like this — data plus pagination metadata:

page
The current page number of the result set (here: page 1).
results
The array of movie records returned on this page.
total_pages
How many pages exist in total — tells your loop when to stop.
total_results
The total number of records across all pages.

🔢 Status codes you will meet

200 OK — the request worked; use the data.
400 Bad Request — your parameters are wrong (e.g. a bad page number).
401 Unauthorized — your API key is missing or invalid.
404 Not Found — the resource or endpoint does not exist.
429 Too Many Requests — rate limit hit; this is why pagination loops sleep between calls and retry after a pause.
5xx Server Error — the API is having problems; wait and retry later.

🔑 Why API keys?

An API key proves who you are so the provider can authenticate you. It also lets the provider enforce quotas and rate limits — how many requests you may make per minute or per month — and track usage for billing. Keys are usually sent as a query parameter (?api_key=YOUR_KEY) or in a request header.
