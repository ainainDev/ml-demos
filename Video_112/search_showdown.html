The lesson

Press “🏁 Race them!” and watch: grid visits every corner of the space, random darts across it — then compare how much each spent to find its best.

Like the video's real demo (108 grid combos = 540 fits vs n_iter=10 = 50 fits), random search usually finds a near-optimal combo at a fraction of the cost. The exact numbers differ each random run — try it a few times.
