🎯 ColumnTransformer — "aam zindagi" vs "mentos zindagi"

One dataset, mixed column types. Do it by hand (left) or in one call (right).

😓 aam zindagi — manual way

1️⃣ SimpleImputer on fever (missing values)
2️⃣ OrdinalEncoder on cough (mild < strong)
3️⃣ OneHotEncoder(drop='first') on gender, city
4️⃣ np.concatenate everything back together…
5️⃣ …and repeat it ALL again for X_test 😩
X1 = SimpleImputer().fit_transform(X_train[['fever']])
X2 = OrdinalEncoder(...).fit_transform(X_train[['cough']])
X3 = OneHotEncoder(drop='first').fit_transform(X_train[['gender','city']])
X_train_t = np.concatenate([X1, X2, X3, X_train[['age']]], axis=1)

😎 mentos zindagi — ColumnTransformer

✅ declare each (name, transformer, columns) once
✅ remainder='passthrough' keeps age untouched
✅ one fit_transform on train, transform on test
from sklearn.compose import ColumnTransformer
transformer = ColumnTransformer(
  transformers=[
    ('tm1', SimpleImputer(), ['fever']),
    ('tm2', OrdinalEncoder(categories=[['mild','strong']]), ['cough']),
    ('tm3', OneHotEncoder(drop='first'), ['gender','city'])],
  remainder='passthrough')
X_train_t = transformer.fit_transform(X_train)
X_test_t  = transformer.transform(X_test)
